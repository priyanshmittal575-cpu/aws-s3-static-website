# Static Website Hosting Simulation (S3 Style)

Cloud-ready static website architecture demonstrating clean asset organization, custom error handling, and S3-style deployment structure.

## Features & Overview
- Built as part of the **B.Tech 1st Year Web Designing & Full-Stack Development** project series.
- Clean, modular separation of markup, styling, client-side logic, and backend/database schemas.

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript

## How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/priyanshmittal575-cpu/aws-s3-static-website.git
   cd aws-s3-static-website
   ```
1. Open `index.html` directly in any modern web browser (Chrome, Edge, Firefox).
